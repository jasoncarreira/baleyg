# #67 native local-update reference measurement

## Gate and reproduction

Run `python3 tools/verify-67-performance.py` from this checkout on the `mac-mini-m5-pro-v1` host (Mac17,16, Apple M5 Pro). The script builds the release CLI and creates a fresh private scratch tree outside the source checkout on **every** invocation. It generates the version-1 canonical cohorts and compares `manifest.json` as exact bytes to `tools/synthetic-cohorts/manifest-v1.json` (SHA-256 `8b8deea8592cfd069a1500bcad9d634a8b4d343477e769b2f2aed0dd61bee046`). The generated manifest holds each file's relative path, byte length and SHA-256; its exact-byte comparison admits only the pinned files. No prior timings or database are reused.

Each size has one **untimed cold initialization**. Twenty timed warm publications each change one distinct canonical Python leaf (`C{size}0000.py` through `C{size}0019.py`). The script observes that file's `f0` numeric literal in the exact pinned output and increments it by one with **identical byte width**: `1→2` in medium and four-digit `XXXX0→XXXX1` in large. Every selected revision has one genuinely changed document, with the other pinned cohort files intact. No cold setup or declaration-surface fallback time is labeled local p95. The monotonic subprocess wall clock includes the real CLI request, capture, native assembly, class projection, transaction, durable commit, completion and JSON status. It excludes corpus generation, first initialization, independent SQLite inspection, and the separate cold oracle. Each timed run joins its **own returned index generation/revision** to `revision_documents`, `document_versions`, `native_version_declarations`, `native_version_calls` and `native_version_control_regions`, and fails if any medium language has fewer than 50,000 produced native facts or large has fewer than 500,000 in total. The script checks floors before calculating nearest-rank p95 (20 samples; it stops early after two misses, when a passing p95 is mathematically impossible), then enforces medium ≤2 s and large ≤5 s. No setup/index initialization time is labeled local p95.

Writer rows and bytes are the production writer's per-family counters for SQLite-bound row values, printed to release CLI stderr **after successful commit** and grouped into manifest/native/graph/class and total. They are **not** `dbstat` table payload, SQLite indexes, WAL overhead, or file-system byte growth. Every timed publication checks family totals and **zero reused occurrence reads** on the writer transaction; independent Rust tests cover the same invariant. Emitting these postcommit counters is included in the timed CLI wall clock; parsing them afterward is excluded. One full medium declaration-surface update is timed **separately** from proven-local p95. A fresh isolated cold native publication from the modified source snapshot provides the oracle. Selected-manifest native/source/graph/class rows are content-hashed and compared; it does not reuse stored `F`/projection tables as an oracle. A failed floor, parity or p95 exits nonzero and requires an owner decision, without changing thresholds or product paths.
