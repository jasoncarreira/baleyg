# Decision 0002: authenticated SCIP facts and publication-time rejoin

- **Status:** prospective docs-only #11A amendment; no deployed importer, checker, schema, or migration
- **Scope:** `../contract-v1.md` and `../publication-rejoin-vectors-v1.md`
- **Compatibility:** #22 canonical bytes, #38 native records, #47 declaration history, #52 revision/warnings; legacy #26 `SemanticCapture` `formatVersion:1` and its example bytes stay immutable.

## Owner decisions and the narrow boundary

The owner approved native-publication rejoin of unchanged-document semantic evidence from an authenticated earlier capture, rather than copying old occurrence IDs or claiming another producer run. `derivedFrom.recordKind` names **raw** `occurrence|symbolInformation|relationship`, not destination families. Future #27–#30 use a **new** `CapturedScipFactV1` envelope only; this decision does not edit their paused issues. The full fact digest is `SHA-256(UTF8("baleyg.semantic-fact.v1\0") || #22 canonicalBytes(envelope))`. Captured provenance has `derivedFrom:null`; minted proof carries `{provenanceId,recordKind,factDigest}`. Only that verified link permits an r2 proof to retain an r1 `SemanticBasis`. Do not infer calls, dispatch, reference resolution or an `extends|implements|overrides` relationship from raw SCIP flags alone.

## Resolved v1 shape choices

1. **Index scope:** Preserve each `Index.external_symbols` entry as `scope:"index"` `symbolInformation` and each nested relationship as `scope:"index"` `relationship`, with `relativePath:null,positionEncoding:null`. Such envelopes are authenticated capture inventory only. They cannot claim a local declaration, local relationship destination, A anchor, document provenance/coverage or language-specific fact. No invented document path or fourth record kind. Document entries carry `scope:"document"` and concrete path/encoding.
2. **Document uniqueness:** Within one authenticated Index, reject any duplicate `Document.relative_path` *before* fact extraction, including two documents with different `language` values. Validate each path against its admitted source root and language/source-set binding. Never concatenate documents or use map overwrite/first-wins.
3. **Ranges:** A required primary occurrence range is precisely one of `legacy` with 3 or 4 nonnegative int32 values; `singleLine` with `{line,startCharacter,endCharacter}`; or `multiLine` with `{startLine,startCharacter,endLine,endCharacter}`. An optional enclosing range is the same variant or explicit null. Reject a legacy and typed variant both present, including conflicting enclosing variants, or a missing/empty primary range. Typed protobuf `snake_case` maps to these exact camel-case JSON field names; every numeric field, including implicit protobuf zero, is present in JSON. No fallback from `position_encoding=0` or absent value: reject unless its wire occurrence explicitly declares one of 1=UTF-8, 2=UTF-16, 3=UTF-32. Reject unknown enum values, invalid scalar/CRLF positions, reversed ranges or range outside authenticated source bytes. Conversion to UTF-8 measured offsets occurs **after** digesting raw coordinates. If protobuf cannot preserve presence of an explicit default, only the value is carried, not an invented presence bit. For an enclosing range, no variant means null (not an empty legacy array).
4. **Field disposition:** The table below is exhaustive for the pinned `scip 0.10.0` generated messages. Decode authenticated binary (not JSON serialization of protobuf); retain original artifact bytes/hash, pinned decoder version and a reproducible envelope inventory. Known display/presentation data may be omitted from the fact digest because the whole authenticated binary artifact hash still protects them. Reject unknown fields at every decoded level and unknown semantic enum/role values rather than silently digesting less than the producer asserted. Changing decoder interpretation or selected fields requires a new envelope version **and digest domain**. A newly captured JSON producer may use the same closed envelope and digest rule only with authenticated original bytes/manifest and a pinned, reproducible raw-field mapping; its JSON must not pretend to be binary SCIP or reuse the immutable legacy #26 `SemanticCapture` example.

| SCIP field (pinned `scip 0.10.0`) | v1 disposition |
|---|---|
| `Index.metadata` | Authenticated admission/profile/root/toolchain context, not an envelope field; validate all required manifest bindings; do not derive local facts. |
| `Index.documents` | Iterate all; validate unique relative paths, language and root before extraction; order does not alter deduplicated claim identity. |
| `Index.external_symbols` | Capture symbol-information and nested relationship envelopes with index scope and null document coordinates; no local destination proof. |
| `Document.language`, `relative_path`, `position_encoding` | Validate language/path against admitted tuple; preserve path and numeric position encoding in each envelope. Require explicit 1, 2 or 3. |
| `Document.occurrences`, `symbols` | Emit one raw occurrence/symbol-information envelope per entry, and one relationship envelope per nested relationship; collapse byte-identical envelopes in the same authenticated tuple before lookup. |
| `Document.text` | Presentation/source convenience only: omit from fact digest; when present require byte-for-byte equality with authenticated source document bytes. |
| `Occurrence.range`, `single_line_range`, `multi_line_range`, `enclosing_range`, `single_line_enclosing_range`, `multi_line_enclosing_range` | Select exactly one variant per supplied primary/enclosing range as defined above; primary mandatory, enclosing nullable; digest unconverted numeric fields. Reject mixed variants. |
| `Occurrence.symbol`, `symbol_roles`, `syntax_kind` | Digest original string and numeric values (including empty/zero); roles must use only known bits 1,2,4,8,16,32,64; syntax kind must be a known pinned enum. Do not turn a bit into an inferred call/dispatch. |
| `Occurrence.override_documentation`, `diagnostics` | Omit presentation data from fact digest; retain under original artifact hash, reject unknown fields recursively in diagnostic messages. |
| `SymbolInformation.symbol`, `kind`, `display_name`, `enclosing_symbol` | Digest original symbol/string/numeric enum values, including empty/zero defaults; reject unknown kind enum. |
| `SymbolInformation.relationships` | Emit **separate** relationship envelope per entry, preserving source and target direction and all four flags independently (both reference and implementation may be true). |
| `SymbolInformation.documentation`, `signature_documentation` | Omit presentation strings from fact digest; retain under original artifact hash; reject nonempty semantic signature occurrences, and recursively reject unknown fields in nested signature. |
| `Relationship.symbol`, `is_reference`, `is_implementation`, `is_type_definition`, `is_definition` | Digest target spelling, enclosing source spelling, and all four decoded booleans; no synthetic destination relation kind. |
| `Metadata.version`, `tool_info`, `project_root`, `text_document_encoding` | If metadata is present, accept only known protocol enum; validate supplied project root, tool identity/version and UTF-8 text-encoding declaration against authenticated admission/profile (reject mismatch/unsupported). An absent metadata message is allowed **only** when the external authenticated manifest supplies those required bindings; none enter per-fact digest. |
| `ToolInfo.name`, `version`, `arguments` | Validate name/version when supplied against captured producer/profile; arguments are authenticated context omitted from fact digest, never an inferred semantic claim. |

The closed envelope has exactly `{formatVersion:1,recordKind,scope,relativePath,positionEncoding,raw}`. `scope:"document"` requires a containing document path and encoding; `scope:"index"` allows only `symbolInformation|relationship` and requires both fields null. For `occurrence`, `raw` has exactly `{range,enclosingRange,symbol,symbolRoles,syntaxKind}`. For `symbolInformation`, exactly `{symbol,kind,displayName,enclosingSymbol}`. For `relationship`, exactly `{sourceSymbol,targetSymbol,isReference,isImplementation,isTypeDefinition,isDefinition}`. String defaults are empty; numeric defaults are zero; boolean defaults are false; only `enclosingRange` may be null. `range` variants have exactly `{encoding:"legacy",values:[...]}`, `{encoding:"singleLine",line,startCharacter,endCharacter}` or `{encoding:"multiLine",startLine,startCharacter,endLine,endCharacter}`. Required nulls and unknown-key rejection follow #22. Reject values outside safe unsigned JSON integers even before attempted canonicalization; signed negative positions/roles/enums fail admission. No producer/fixture IDs, source revision/hash, converted ranges, resolution, dispatch, native anchors, destination family or freshness enter these envelope bytes.

## Authenticated proof and transaction

Bind a captured proof ID to exactly the #22 canonical tuple `{producerId,artifactHash,sourceSetId,sourceRevision,language,relativePath,factDigest}` using `SHA-256(UTF8("baleyg.capture-proof.v1\0") || canonicalBytes(tuple))` (full lowercase hash, no ordinal/claim discriminator). For index scope only, `language:null,relativePath:null`; its digest-addressed inventory claim is **not** a document `Provenance` row and cannot be used as a minted local `derivedFrom` link. For document scope both are concrete and language comes from the authenticated containing document. The tuple fields come from admitted authenticated artifact, manifest and envelope, not a guessed protobuf proof ID. Deduplicate identical envelopes **per authenticated tuple** before deriving the proof ID and before exactly-one lookup; preserve distinct claims with different digest or authenticated context. Check the inventory against the original bytes and reject a digest collision, forged ID, missing match or multiple distinct envelope bindings. A matching digest by itself is neither authentication nor an anchor join.

Native publication validates original artifact/binary digest, manifest and inventory atomically, then converts coordinates and joins A facts to a measured r2 native candidate. A must have identical authenticated bytes/key and **one distinct** compatible measured r2 source candidate at exact span/kind/source set, not a name or nearest overlap. Missing/ambiguous A source, invalid conversion or unavailable measurement fails the entire A tuple; malformed captured artifact fails the entire producer artifact. If another revision publishes despite artifact rejection, publish selected diagnosed `failed` coverage for every requested attributable tuple, without producer facts; cancellation publishes nothing. An independently invoked *later import* uses a compare-and-swap against the published revision: a lost race cannot write a partial overlay. These are separate transaction modes.

Mint new r2 associations/provenance with r2 native occurrence IDs, owner, ranges, target revision and destination bytes; never copy r1 occurrence/target IDs or rewrite captured basis. A changed B does not rejoin B. A fact may target changed B only when exactly one compatible measured r2 B declaration verifies the **same stable syntax ID** as the captured internal target; the new A proof is `possiblyStale`, `staleTarget=false`, and cannot expand. If B has no unique verified same-ID target, omit only A facts dependent on B; independent A facts remain, A gets `partial` coverage with actual `observedRoles` and a diagnostic. A source failure instead makes all A selected `failed`. Genuine producer-external targets stay external; never turn an absent internal target into external. Freshness rule 2 marks every minted r1-basis/r2 proof `possiblyStale` despite unchanged A bytes; changed source bytes are only eligible for #47 stale declaration history. `staleTarget=true` remains invalid in v1. Warnings-v1 and #47 latest eligible tuple/document/returned-declaration scope remain unchanged; #40 traversal and #41 observed importer integration are separate gates.

## Alternatives and review

Rejected: retroactively reinterpreting #26 `SemanticCapture` v1, digesting destination records, first-wins paths/anchors, index-level symbols attributed to a random document, allowing unknown extensions, and promoting captured r1 proofs to fresh. This record resolves documentation shape, not a runnable decoder or test corpus. Independently review the vectors and native decoder evidence before implementing 11B; no executable schema/checker, fixtures, Rust importer, #38/#40/#41 or paused issue edit is in this PR.
